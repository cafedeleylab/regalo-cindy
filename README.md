# Gift card para Cindy

Landing de cumpleaños para Cindy con la animación de apertura y la tarjeta del curso de Arte Latte de Café de Ley.

Abre `index.html` para verla. Para publicarla como sitio estático, sube `index.html` y `og-cindy-box.png` a la raíz del sitio. La tarjeta y las animaciones ya están integradas en el HTML; `og-cindy-box.png` es la vista previa al compartir el enlace.

`og-cindy.png` y `build_og.py` conservan la versión anterior de la vista previa.
